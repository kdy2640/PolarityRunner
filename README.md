## About the Game

**Polarity Runner**는 Steam 게임 **Polarity**를 참고하여 제작한 1인칭 퍼즐 플랫포머 모작 게임입니다.

플레이어는 자신의 극성을 전환하며 장벽을 통과하고, 큐브와 입력기를 활용해 스테이지의 퍼즐을 해결합니다.  
각 스테이지에서 **Goal 오브젝트**에 도달하는 것이 목표이며, 극성에 따라 오브젝트의 상호작용 결과가 달라집니다.

## Features

- **극성 전환 시스템**: 빨강 / 파랑 극성을 전환하며 오브젝트와 상호작용
- **극성 장벽**: 같은 색의 물체만 통과할 수 있는 장벽 기믹
- **큐브 상호작용**: 큐브를 집고 던져 입력기를 작동시키는 퍼즐 구조
- **입력기 시스템**: 같은 색의 큐브에 반응하는 장치 구현
- **플랫포머 기믹**: 점프대와 이동 발판을 활용한 스테이지 구성
- **레벨 재시작 기능**: 진행이 막혔을 때 현재 스테이지를 다시 시작 가능

## Controls

- **WASD / 방향키** : 이동
- **Mouse** : 시점 조작
- **Shift** : 달리기
- **Space** : 점프
- **F** : 극성 전환
- **E** : 큐브 집기
- **Left Click** : 큐브 던지기
- **R** : 현재 레벨 다시 시작
- **Esc** : 게임 종료

## Stages

- **Stage 1**: 극성 전환과 장벽의 기본 메커니즘 학습
- **Stage 2**: 큐브를 집고 던져 입력기를 작동시키는 방식 학습
- **Stage 3**: 점프대와 이동 발판 기믹 활용
- **Stage 4**: 모든 기믹을 종합하여 최종 목표 지점까지 도달
